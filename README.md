# Zepto Data Analysis

This project analyzes Zepto e-commerce inventory and product data using SQL.

## Technologies Used
- SQL
- PostgreSQL
- CSV Dataset
- GitHub

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Product Category Analysis
- Inventory Analysis
- SQL Business Queries

## Insights Generated
- Top discounted products
- Product category trends
- Stock availability analysis
- Pricing analysis

## Dataset
The dataset contains product inventory and pricing details from an e-commerce platform.

## Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE Statements
